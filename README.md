# エスパーティア（ESPER TIER）

親がこっそり作ったティア表を、子が何人読み当てられるか勝負するパーティゲーム。
スマホのブラウザだけで動きます。サーバーもアカウントも不要です。

## 2つの遊び方

| | オンライン（おすすめ） | 1台モード |
|---|---|---|
| 端末 | 各自のスマホ | 1台を回す |
| 通信 | 必要 | 不要 |
| 子の予想 | 全員いっせい・制限時間あり | 1人ずつ順番 |

オンラインは無料の公開MQTTブローカーを中継に使っています（アカウント登録なし）。
万一ブローカーが落ちていても、**1台モードならオフラインで遊べます**。

## ルール

1. **大お題をみんなで決める** … 例「好きなコンビニスイーツ」「LoLの好きなチャンピオン」
2. **親が項目を5個えらぶ** … 大お題の中から親が自由に入力。全員に公開されます
3. **親がこっそりティア分け** … S/A/B/C/D に並べて確定
4. **子はいっせいに予想** … 制限時間内に各自のスマホで親のティア表を予想
5. **全員ぶん公開＆採点**

### 得点
| | |
|---|---|
| ◎ 親と同じティア | +3点 |
| △ 1つ隣のティア | +1点 |
| ✕ 2つ以上ずれ | 0点 |
| 🎯 5個ぜんぶピタリ（完全一致ボーナス） | +5点 |
| 👑 親の点 | そのラウンドの**子の平均点** |

1ラウンドの満点は **20点**（15点＋ボーナス5点）。

親は「伝わるけど自分らしい表」を作るのが得。ひねりすぎてもベタすぎても損します。
設定したラウンド数ぶん親が交代して、合計点がいちばん高い人の勝ち。

項目は5個、ティアは S/A/B/C/D の5段で固定です。

### 設定（ホストがロビーで変更）
- 制限時間 60 / 90 / 120秒 / なし
- 大お題を「ずっと同じ」か「親が毎回決める」か
- ラウンド数

## 使い方

1. ホストが「部屋をつくる」→ 4文字のルームコードが出る
2. 「🔗 参加リンクをコピーして送る」でLINE等に貼る（開くだけで参加画面にコードが入ります）
3. 他のメンバーは「部屋に入る」でコードと名前を入力
4. 3人以上そろったらホストが「ゲーム開始」

### 途中でやめたい・トラブった時
右上の **⋯ メニュー**（ホストのみ操作可）から:
- **ここで終了して結果発表へ** … やったラウンドまでのスコアで優勝者を決める
- **このラウンドを飛ばす** … 親がトイレに行った等
- **ロビーにもどす** … スコアをリセットして最初から

### ホストが落ちたら
ホストの端末が進行役ですが、**11秒ほど配信が途絶えると、残っている人の中から自動で進行役が交代します**。
その時やっていたラウンドだけはやり直しになります（親のティア表と全員の予想は他の端末に送っていないため、引き継げません）。スコアとそれまでの記録は保持されます。
抜けた人は、ホーム画面の「↩️ さっきの部屋にもどる」から復帰できます。

⚠️ それでもホストはなるべくアプリを開いたままにしてください（他のアプリに移るとタイマーが止まります）。画面スリープはWake Lockで抑止しています。

## 配置のしかた

`dist/index.html` が**すべて入った単一ファイル**です。これ1つ置けば動きます。

- **Netlify Drop**（いちばん手軽）: https://app.netlify.com/drop に `dist` フォルダをドラッグ
- **GitHub Pages**: `dist/index.html` をリポジトリに置いて Pages を有効化
- 置いたURLをスマホで開き、Safariの共有メニューから **「ホーム画面に追加」** しておくと起動が速い

### 開発
```sh
# ソースは index.html / style.css / app.js / mqtt.min.js に分かれています
./build.sh        # → dist/index.html を再生成
python3 -m http.server 8000   # ローカル確認
```

## 仕組みと制限
- ホスト端末が進行と採点を担当し、他の端末へ状態を配信します
- **親のティア表と他人の予想は、公開前は他の端末に一切送っていません**（送信データを実機テストで検証済み）
- ホスト端末のメモリ上には全データがあるため、ホストがPCの開発者ツールを使えば理論上は覗けます。スマホではまず不可能ですが、気になる場合はホストを持ち回りで
- 通信が切れても、復帰すれば自動で現在の状態に追いつきます
- ホストが抜けた場合は自動で交代します（進行中のラウンドのみやり直し）
- 親が抜けたまま15秒経つと、そのラウンドは自動で飛ばします
